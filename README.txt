# Taipei Girls Trip PWA

## 內容
- `index.html`: 手機優先旅行規劃器
- `manifest.webmanifest`: PWA 安裝設定
- `sw.js`: 離線快取
- `icon-192.png` / `icon-512.png`: App 圖示

## 重要：如何安裝到 iPhone
PWA 必須放在 HTTPS 網址上，不能只把 ZIP 解壓縮後就直接安裝。
1. 將整個資料夾部署到支援 HTTPS 的靜態網站（例如 GitHub Pages）。
2. 在 iPhone 用 Safari 開啟網站網址。
3. 點「分享」→「加入主畫面」→「加入」。

## 資料保存及分享
- 編輯版的修改自動保存在該 iPhone 的 Safari 本機儲存空間。
- 請在「分享與設定」匯出 JSON 備份，避免清除 Safari 網站資料造成遺失。
- 分享給朋友：匯出 JSON，朋友開啟同一個網站後，在「分享與設定」匯入即可查看該次快照。
- 朋友匯入的資料是自己的本機副本；不會即時同步你之後的修改。若要自動更新的唯讀分享網址，需要另加雲端資料庫或發布流程。

## 注意
- 天氣按鈕查詢台北「目前天氣」，不會預測 2026/12/28–2027/01/01 的天氣。
- 交通時間是初步估算，請以出發當日 Google Maps 為準。
- 請勿把含有個人訂單編號的備份公開張貼。
